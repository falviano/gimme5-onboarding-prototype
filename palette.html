Colour

La palette di Gimme5 è strutturata su token semantici. Ogni colore ha un ruolo specifico nell'interfaccia — dal brand primario ai feedback di sistema, dagli stati interattivi all'accessibilità.

Text

Border

Borders & Focus

Tre livelli di bordo + uno stile focus ispirato a Wise: doppio bordo nero via box-shadow 0 0 0 1.5px #000. Il global reset rimuove l'outline nativo — il focus visivo vive nel box-shadow.

Default — separatori card, icon-box, righe lista --border-default · #e8e8e8
Strong — input default, chip, checkbox non selezionato --border-strong · #d0d0d0
Brand — checkbox checked, dcheckbox selezionato --border-brand · #F55A27
Focus — stile Wise: doppio bordo nero su input attivo/filled --border-focus · #000000 + box-shadow 1.5px

Accessibility

Contrast

Rapporti di contrasto per le combinazioni testo/sfondo più usate nel prototipo. WCAG AA richiede 4.5:1 per testo normale, 3:1 per testo grande (18px+ o 14px+ bold).

Combinazione Anteprima Rapporto AA normale AA grande
#000000 su #F55A27 CTA button 4.6 : 1 ✓ Pass ✓ Pass
#ffffff su #33110A Fund chip abbr 14.2 : 1 ✓ Pass ✓ Pass
#000000 su #ffffff Testo card 21 : 1 ✓ Pass ✓ Pass
#3a3a3a su #ffffff Label secondaria 10.7 : 1 ✓ Pass ✓ Pass
#5c5c5c su #ffffff Testo supporto 7.2 : 1 ✓ Pass ✓ Pass
#5c5c5c su #ebebeb Testo su page bg 5.9 : 1 ✓ Pass ✓ Pass
#b0b0b0 su #ffffff Placeholder 2.3 : 1 — Exempt — Exempt
#15803d su #f0faf4 Successo 5.1 : 1 ✓ Pass ✓ Pass
#8d8d8d su #efb19d Disabled btn 1.9 : 1 — Exempt — Exempt

* Placeholder e disabled sono esplicitamente esenti da WCAG 2.1 §1.4.3: il placeholder è testo decorativo/suggerimento, il disabled è un componente inattivo. Nessuna azione richiesta.
